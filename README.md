# 🏝️ Island Mascot (iOS App + Home Screen Widgets + Dynamic Island)

Приложение-маскот (виртуальный питомец Бубу) для iPhone под iOS 16.1+ с поддержкой:
- **Виджетов на рабочем столе** (WidgetKit: маленький и средний размер, автономная смена занятий каждые 20 минут).
- **Dynamic Island и Live Activities** (ActivityKit: питомец живет в «динамическом острове», когда приложение свернуто или закрыто, а также на экране блокировки).
- **Автономной жизни**: питомец сам меняет занятия, хочет есть, спать, играть, делится мыслями и реагирует на уход.

---

## 📱 Как работает приложение

1. **Главный экран (SwiftUI):**
   - Интерактивный маскот с анимацией эмоций и мыслей.
   - Шкалы состояния: 🍔 **Сытость**, ⚡ **Энергия**, 💖 **Счастье**.
   - Кнопки взаимодействия: Покормить, Поиграть, Уложить спать, Погладить.
   - Переключатель отображения в **Dynamic Island**.
2. **Dynamic Island (Остров вверху экрана):**
   - **Компактный вид (свернутый):** мордочка питомца слева и уровень настроения/энергии справа.
   - **Развернутый вид (по долгому нажатию на остров):** крупный персонаж, текущее занятие, шкалы показателей и облачко с мыслями.
3. **Виджеты на домашнем экране:**
   - **Small (2x2):** персонаж крупным планом, текущее настроение и статус.
   - **Medium (2x4):** питомец с комнатой, всеми показателями и мыслями.

## 🛠️ Как получить готовый `.ipa` файл за 2 минуты (Бесплатно через GitHub Actions)

> ⚠️ **Важно знать об iOS:**  
> Apple разрешает компилировать бинарники с **Dynamic Island (ActivityKit)** и **виджетами (WidgetKit)** только на базе среды macOS/Xcode. Напрямую на чистом Windows без macOS-компилятора собрать бинарный Mach-O файл невозможно.  
> **Решение:** В репозитории уже настроен автоматический CI/CD робот [`.github/workflows/build-ipa.yml`](.github/workflows/build-ipa.yml), который бесплатно собирает `.ipa` на серверах Apple (macOS) в GitHub!

### Шаги для сборки:
1. Зайдите на [GitHub.com](https://github.com) и создайте новый репозиторий (можно приватный), например `IslandMascot`.
2. Загрузите файлы этого проекта в репозиторий:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Island Mascot"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/IslandMascot.git
   git push -u origin main
   ```
3. Откройте вкладку **Actions** в вашем репозитории на GitHub.
4. Выберите воркфлоу **Build iOS IPA** и нажмите **Run workflow** -> зеленую кнопку **Run workflow**.
5. Через 2-3 минуты сборка завершится, и в блоке **Artifacts** появится готовый к скачиванию файл **`IslandMascot-iOS-IPA`** (внутри архив с файлом `IslandMascot.ipa`).

## 📲 Как установить `.ipa` на iPhone с Windows

После того как вы скачали `IslandMascot.ipa`:

### Способ 1: Через Sideloadly (Самый простой и рекомендуемый для Windows)
1. Скачайте и установите бесплатную программу [Sideloadly](https://sideloadly.io/) на компьютер.
2. Подключите iPhone к компьютеру кабелем (при запросе на телефоне выберите *«Доверять этому компьютеру»*).
3. Перетащите файл `IslandMascot.ipa` в окно Sideloadly.
4. Введите свой Apple ID (используется для бесплатной подписи приложения на 7 дней).
5. Нажмите **Start**. Приложение появится на рабочем столе iPhone.
6. На iPhone перейдите в:  
   *Настройки* → *Основные* → *VPN и управление устройством* → выберите ваш Apple ID → нажмите *«Доверять»*.
7. Включите режим разработчика: *Настройки* → *Конфиденциальность и безопасность* → *Режим разработчика* (включить и перезагрузить телефон).

### Способ 2: Через AltStore
- Установите AltServer на Windows и установите приложение через AltStore.

### Способ 3: Через TrollStore (если поддерживается версия iOS)
- Если у вас iOS 14.0–16.6.1 / 17.0 с установленным TrollStore, просто перешлите `.ipa` файл в Telegram/AirDrop и откройте через TrollStore — приложение установится навсегда без ограничений подписи.

## 🎯 Настройка на телефоне после установки

1. Запустите приложение **Island Mascot** один раз, чтобы активировать маскота.
2. Включите тумблер **Dynamic Island** в приложении (при запросе разрешите отображение Live Activities).
3. Смахните приложение вверх — питомец сразу появится в «острове» вверху экрана!
4. Чтобы добавить виджет:
   - Зажмите палец на пустом месте экрана телефона.
   - Нажмите **«+»** в левом верхнем углу.
   - Найдите в поиске **Island Mascot** и выберите понравившийся размер виджета.
